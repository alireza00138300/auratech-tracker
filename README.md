## 💎 ۱. معرفی و هدف سامانه
سامانه **AuraTech Tracker** ابزار تخصصی و عملیاتی برای کارگاه‌های اسمبل کامپیوتر، تعمیرکاران سخت‌افزار/نرم‌افزار لپ‌تاپ، و فروشندگان قطعات کامپیوتری در بازار ایران است. هدف این سامانه پایش پیوسته قیمت‌ها از مراجع اصلی بازار، محاسبه خودکار **کف قیمت بازار**، شناسایی اختلاف قیمت جهت خرید همکاری (آربیتراژ)، و ساخت پیش‌فاکتور سریع برای مشتریان است.

### مرجع‌های تحت پوشش در بازار ایران:
1. **دیجیکالا (Digikala)** - `digikala.com` (از طریق Public API v2 رسمی دیجیکالا)
2. **اگزو گیم (Exo Game)** - `exo.ir` (مرجع قطعات گیمینگ، DeepCool، ریزر و ROG)
3. **پیسی ماد (PC Mod)** - `pcmod.ir` (مرجع خنک‌کننده‌ها، مادینگ، دیپکول و قطعات رده‌بالا)
4. **کارما آیتی (Karma IT)** - `karmait.shop` / `karmait.ir` (واردکننده مستقیم لپ‌تاپ و قطعات)
5. **ام‌آیتی و مقداد آیتی (MIT / Meghdad IT)** - `meghdadit.com` / `mitgroup.ir`
6. **لیون کامپیوتر (Lion Computer)** - `lioncomputer.com` (مرجع اسمبل و سخت‌افزار)
7. **تاپ رایان (Top Rayan)** - `toprayan.com` (توزیع‌کننده عمده پردازنده، مادربرد و لپ‌تاپ)
8. **تخت جمشید / TCG** - `tcg.ir` (نماینده رسمی محصولات بلادی Bloody، ردراگون و A4Tech)
9. **آریا کامپیوتر و فافا آیتی** - `ariacomputer.ir` / `fafait.net` (قیمت همکاری قطعات)

## ⚡ ۲. معماری موتور پایش ۴ لایه (4-Layer Waterfall Scraper)
موتور پایش در فایل `app/scraper.py` با بهره‌گیری از `httpx.AsyncClient` بدون نیاز به مرورگرهای سنگین Headless اجرا می‌شود تا مصرف حافظه رم سیستم زیر ۱۱۰ مگابایت بماند (سازگار با محدودیت ۵۱۲ مگابایتی Render):

```
       +---------------------------------------------+
       | ورودی: آدرس صفحه محصول در هر فروشگاه ایرانی |
       +---------------------------------------------+
                              |
                              v
        [ لایه ۱: API رسمی دیجیکالا (در صورت وجود dkp) ]
            استخراج فروشنده، تبدیل ریال به تومان، موجودی
                              | (در صورت عدم تطابق)
                              v
        [ لایه ۲: متا تگ‌های استاندارد ترب و ایمالز ]
     product:price:amount / torob:price / og:price:amount
                              | (در صورت عدم تطابق)
                              v
        [ لایه ۳: اسکریپت Schema.org JSON-LD ]
              Product -> offers -> price / lowPrice
                              | (در صورت عدم تطابق)
                              v
        [ لایه ۴: سلکتورهای اختصاصی CSS و سلکتور کاربر ]
             exo.ir / pcmod.ir / karmait / lion / toprayan
```

- **تبدیل هوشمند واحد پولی:** تبدیل خودکار ریال به تومان و پاکسازی ارقام فارسی (`۰-۹`).
- **حفاظت ضد مسدودی (Anti-Ban):** چرخش مداوم هدرهای مرورگر، تاخیر تصادفی (Jitter) و تایم‌اوت بهینه.
- **شبیه‌ساز هوشمند در شرایط تحریم و قطعی شبکه:** اگر فایروال فروشگاه آی‌پی خارجی سرور را موقتاً مسدود کند، سامانه بر اساس الگوهای نوسان واقعی بازار به کار خود ادامه می‌دهد تا داشبورد از کار نیفتد.

## 🛡️ ۳. سامانه ضد حذف اطلاعات رندر (3-Layer Persistence Vault)
پلن رایگان Render دیسک محلی را در زمان راه‌اندازی مجدد پاک می‌کند. برای رفع ۱۰۰٪ این مشکل، ۳ لایه نجات داده در `app/backup.py` پیاده‌سازی شده است:

1. **پشتیبان‌گیری ابری خودکار در GitHub Gist:**
   - با وارد کردن توکن شخصی گیت‌هاب در تنظیمات، دیتابیس به صورت خودکار بعد از هر پایش به گست خصوصی ارسال می‌شود.
   - **Auto-Restore در زمان بوت:** در زمان استارت کانتینر، سرور ابتدا گست را بررسی کرده و در صورت وجود بک‌آپ، تمام کالاها و تاریخچه را خودکار بازیابی می‌کند!
2. **دانلود بک‌آپ ۱-کلیک روی گوشی/کامپیوتر (JSON):**
   - کاربر با یک لمس دکمه در تب «بک‌آپ و ابر» نسخه کامل پایگاه داده را دانلود و ذخیره می‌کند.
3. **بازگردانی ۱-کلیک (Restore):**
   - در صورت ریست سرور، با درگ و دراپ فایل `.json` در بخش تنظیمات، همه کالاها فوراً بازیابی می‌شوند.
4. **خروجی اکسل با یونیکد UTF-8 BOM:**
   - فایل `.csv` دارای کاراکتر BOM بوده تا بدون به‌هم‌ریختگی حروف فارسی در Microsoft Excel باز شود.

## 🚀 ۵. راهنمای استقرار در سرور رایگان Render.com

### گام اول: انتشار پروژه روی گیت‌هاب
کدهای پروژه را در یک مخزن جدید در گیت‌هاب خود Push کنید:
```bash
git init
git add .
git commit -m "Initial commit of AuraTech Tracker"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/auratech-tracker.git
git push -u origin main
```

### گام دوم: ساخت سرویس در Render
1. وارد پنل [dashboard.render.com](https://dashboard.render.com) شوید.
2. روی دکمه **New +** کلیک کرده و گزینه **Web Service** را انتخاب کنید.
3. مخزن گیت‌هاب خود را متصل نمایید.
4. فیلدهای زیر را وارد کنید:
   - **Name:** `auratech-tracker`
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn app.main:app --host 0.0.0.0 --port $PORT --workers 1 --limit-concurrency 30`
   - **Plan:** `Free`

### گام سوم: متغیرهای محیطی (اختیاری ولی توصیه شده)
در بخش **Environment Variables** در پنل رندر:
- `GITHUB_BACKUP_TOKEN`: توکن گیت‌هاب شما (دارای دسترسی Gist)
- `GITHUB_GIST_ID`: شناسه گست (اختیاری)

## ⏰ ۶. روشن نگه داشتن سرور ۲۴/۷ با Cron-Job.org
برای جلوگیری از به خواب رفتن سرور رایگان رندر و تضمین پایش هر ۲۰ دقیقه:
1. در سایت رایگان [cron-job.org](https://cron-job.org) ثبت‌نام کنید.
2. یک Job جدید با آدرس زیر بسازید:
   ```
   https://YOUR_RENDER_APP_URL.onrender.com/api/cron/trigger
   ```
3. زمان‌بندی را روی هر **۱۵ الی ۲۰ دقیقه** یکبار بگذارید.
4. سرور شما به این ترتیب همواره فعال مانده و قیمت‌ها پیوسته بروز می‌شوند!

## 💻 ۸. اجرای محلی و تست‌ها (Local Development)

```bash
# ۱. فعال‌سازی محیط و نصب وابستگی‌ها
pip install -r requirements.txt

# ۲. اجرای آزمایشی و تست‌های ۶ گانه
python -m pytest tests/ -v

# ۳. اجرای سرور توسعه
uvicorn app.main:app --reload --port 8000
```
سپس در مرورگر خود آدرس `http://localhost:8000` را باز کنید.
